# Intube Music - APK Generation Guide

## Quick Install (No APK needed)
1. Open website in Chrome on Android phone
2. Tap 3-dot menu > "Install app" / "Add to Home Screen"
3. App installs directly and works like native app (PWA)

## Generate APK for Distribution

### Using PWABuilder.com (Recommended)
1. Deploy website to production URL (e.g., music.intubemedia.com)
2. Visit https://www.pwabuilder.com
3. Enter production URL
4. Click "Package for stores" > "Android"
5. Set package name: `com.intubemedia.music`
6. Download APK/AAB

### Play Store Submission
1. Create Google Play Developer account (play.google.com/console - $25)
2. Create new app > Name: "Intube Music"
3. Upload AAB from PWABuilder
4. Category: Music & Audio
5. Fill store listing, add screenshots
6. Submit for review (2-7 days)
